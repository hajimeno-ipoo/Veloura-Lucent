# Veloura Lucent

Veloura Lucentは、音源の解析、ノイズ除去、補正、マスタリング、試聴比較、
書き出しを行うmacOSネイティブアプリです。音源の状態を見ながら必要な処理だけ
を適用し、元の音楽成分をできるだけ保ちます。

## できること

- 音声ファイルの読み込みとドラッグ＆ドロップ
- `弱い`、`標準`、`強い`の補正プリセット
- ノイズ、低域、高域、ステレオ感の確認と補正
- `自然`、`聴きやすく整える`、`押し出し強め`などのマスタリングプロファイル
- 入力、補正後、最終版のA/B試聴
- 波形、スペクトル、ベクトルスコープ、ラウドネスなどの表示
- Stem ModeによるHTDemucsの4 Stem分離とStem別補正
- 補正後、最終版などの用途別書き出し

## Stem Mode

Stem Modeでは、HTDemucsで入力音源を次の4 Stemへ分けます。

`drums` / `bass` / `other` / `vocals`

分離モデルは利用者が明示的に取得を承認した時だけダウンロードします。モデル本体は
アプリやリポジトリへ同梱せず、macOSのアプリケーションサポート領域へ保存します。

## 書き出し

- 高品質保存
- 配信・納品用 WAV
- CD用 WAV
- 試聴共有用 AAC

補正途中の一時ファイルや内部解析用データは、利用者向けの書き出し一覧には表示しません。

## 対応環境

- macOS 26以降
- Apple Silicon Mac（Stem Modeを使用する場合）

通常補正とマスタリングは、Stemモデルを使わずに実行できます。

## 音源とプライバシー

音源の解析・補正・マスタリングはMac上で行います。リポジトリには実音源や個人の
検証素材を含めません。Stemモデルを取得する場合だけ、選択したモデルの配布元へ
通信します。
