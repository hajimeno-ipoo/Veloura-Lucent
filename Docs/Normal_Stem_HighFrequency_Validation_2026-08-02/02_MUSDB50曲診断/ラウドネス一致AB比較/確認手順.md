# ラウドネス一致A/B比較資料

## 現時点の判断

- 低域は変更しない。
- 最終高域保持と倍音工程は、今回の優先変更対象から外す。
- 現行Air工程で技術的な折り返しを確認したため、修正要否をユーザーの聴感判定へ委ねない。

## 任意で確認する場合

各フォルダで、次の2ファイルだけを比較する。

1. `00_再ミックス入力_-23LUFS.wav`
2. `16_最終版_-23LUFS.wav`

これらは処理前後を確認するための資料であり、ユーザーによる技術的な合否判定は不要である。

## 工程順

1. `00_再ミックス入力_-23LUFS.wav` → `01_音色後_-23LUFS.wav`
2. `01_音色後_-23LUFS.wav` → `03_ダイナミクス後_-23LUFS.wav`
3. `03_ダイナミクス後_-23LUFS.wav` → `05_Air後_-23LUFS.wav`

現行Air工程への9kHz正弦波入力では、入力に存在しなかった21kHz成分が処理後に生成された。修正対象はこの技術的な折り返しである。
