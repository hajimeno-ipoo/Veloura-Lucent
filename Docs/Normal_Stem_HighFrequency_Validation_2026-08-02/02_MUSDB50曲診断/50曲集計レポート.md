# MUSDB公式7秒サンプル50曲 Stem Modeマスタリング工程比較

> このレポートは50曲の`Stem再ミックス→最終版`を集計したものであり、特定の実行における`原音→Stem再ミックス`やStem補正内部の発生工程を判定する資料ではない。元の指摘対象の全工程比較は`VelouraLucent-StemStageDiagnostics-e5a3d718-20260802/工程比較レポート.md`を参照する。

## 結論

- 前回の1曲で確認した変化は、1曲だけの例外ではない。
- 再ミックスから最終版までの20Hz–2kHzは、50曲中央値で`-1.905 dB`だった。ただし全体RMSも`-1.665 dB`であり、全体音量差を除いた低域固有の変化は中央値`-0.156 dB`だった。
- したがって、「低域だけが約1.9dB削られる」という一般化はできない。約1.9dBの大部分は全体音量の変化である。
- 8–20kHzは絶対量では中央値`-0.061〜-0.186 dB`だが、全体RMS差を除くと中央値`+1.348〜+1.519 dB`であり、高域が相対的に前へ移る挙動は46〜47曲で確認した。
- 21–24kHzは絶対量でも50曲中央値`+0.781 dB`、43曲で増加した。全体RMS差を除くと中央値`+2.269 dB`、48曲で増加した。
- 21–24kHz増加の主な発生工程は、音色、ダイナミクス、Airである。倍音工程の増加は小さい。最終高域保持は50曲すべてで音声を変更していない。
- 現行コードのAirと倍音は48kHzのまま`tanhf`を使用し、オーバーサンプリングを行っていない。追加の現行Air工程focused testでは、21kHzを含まない9kHz正弦波入力から21kHzが新たに生成され、Air工程の折り返しを確認した。

## 測定方法

- Hann窓`16,384 samples`、hop`8,192 samples`のSTFTを使用した。
- 全工程WAVを48kHz、同一長、同一チャンネル数で比較した。
- 各帯域のFFTパワーを全フレームで集計し、前工程差と`00→16`の総差をdBで算出した。
- 「RMS差を除いた相対変化」は、帯域差から全体RMS差を引いた値である。
- 各曲を1票として、50曲の中央値、最小値、最大値、増減曲数を集計した。

## 現行コードとの照合

- 音色工程は`MasteringToneStage.applyTone`で、120–420Hz、420–1200Hz、10kHz以上などを別々に調整する。
- ダイナミクス工程は`MasteringDynamicsStage.applyMultibandCompression`で、low、mid、highを圧縮し、9kHz以上のair成分を加算する。
- 倍音工程は`MasteringSaturationStage.applySaturation`で、48kHz信号へ`tanhf`を直接適用する。
- Air工程は`MasteringAirEnhancer.process`で、`tanhf`差分から5.5–10kHzと10kHz以上を生成し、元信号へ加算後、再度`tanhf`を適用する。
- 倍音工程とAir工程には、オーバーサンプリング処理がない。
- 最終高域保持は、50曲すべてのログで`適用 0.0 dB`だった。
- 最終低中域保護は45曲で「150Hz〜500Hzを最大+0.5dB」を実行し、1曲は対象なし、4曲はノイズ保護で見送った。

## 前回1曲との位置づけ

前回の約246.2秒音源では、20Hz–2kHzが`-1.888 dB`、150–500Hzが`-1.808 dB`、21–24kHzが`+0.379 dB`、21–24kHz相対差が`+2.206 dB`だった。

今回50曲の中央値は、それぞれ`-1.905 dB`、`-1.746 dB`、`+0.781 dB`、`+2.269 dB`である。前回値は50曲分布から外れた特殊例ではなかった。

## 判断

1. 20Hz–2kHzの`約-1.9dB`だけを根拠に、全曲へ150–500Hzを`+0.5〜1.0dB`戻す修正は支持できない。全体RMS差を除いた150–500Hzの中央値は`-0.102dB`で、現行の最終低中域保護も45曲で作動している。
2. 高域が全体に対して相対的に前へ移る挙動は、50曲で共通性が高い。特に音色、ダイナミクス、Airが寄与している。
3. 21–24kHzの増加は実測上の共通挙動である。工程別WAVだけでは原因を確定できなかったが、追加の現行Air工程focused testで折り返しを確認した。
4. 9kHz正弦波の21kHz成分は、入力`-176.49 dBFS`からAir処理後`-59.89 dBFS`へ増加した。入力に存在しない21kHz成分が現行Air処理で生成されているため、ユーザーの好みではなく技術的修正対象と判断する。

## 結局どうするか

1. 低域は現時点で変更しない。20Hz–2kHzの約-1.9dBは低域だけの減少ではなく、大部分が全体音量差だったため、150–500Hzを全曲一律に戻す修正は行わない。
2. 最終高域保持は変更対象から外す。50曲すべてで音声を変更していないため、この工程は今回の高域増加原因ではない。
3. 倍音工程も優先対象から外す。21–24kHzの相対増加中央値は+0.027dBで、音色、ダイナミクス、Airより小さい。
4. Air工程を技術的修正対象とする。現行Air工程で9kHz入力から21kHzの折り返しが新たに生成されることをfocused testで確認したため、ユーザーの聴感判定へ委ねない。
5. 音色とダイナミクスの相対的な高域移動は現行コードの帯域調整・高域保持設計と一致しており、今回の折り返し確認だけを理由に変更対象へ含めない。

比較資料として、50曲中央値に近い`Raft Monk - Tiring`と、8–20kHzの相対増加が最大だった`Sambasevam Shanmugam - Kaathaadi`について、再ミックス入力、音色後、ダイナミクス後、Air後、最終版を一定ゲインだけで-23 LUFSへ揃えた。技術的修正の要否はfocused testで確定したため、この比較音源をユーザー判定の必須条件にはしない。
