# Stem Mode マスタリング工程別WAV比較

## 対象

- セッション: `e5a3d718-f8cf-401f-9776-e5644dd0b2b9`
- 固定入力: `stem-remix-48000.wav`
- 実際の最終版: `final-master.wav`
- 使用設定: 「聴きやすく整える」の既定値（目安 -16.7 LUFS / True Peak上限 -1.5 dBTP）
- 工程別WAV: `00_mastering_input` から `16_mastering_finalLoudnessBounds` まで17ファイル
- マスタリング前の既存データ: 原音、分離直後4Stem、補正後4Stem、補正済み純粋加算、Stem再ミックス

## 同じ処理条件であることの確認

- 元のStem再ミックスと `00_mastering_input` のSHA-256は一致した。
- 元の最終版と `15_mastering_finalLowMidBody`、`16_mastering_finalLoudnessBounds` のSHA-256は一致した。
- したがって、この工程別WAVは今回ユーザーが実行したStemマスタリングと同じ入力・設定・最終結果である。

## 測定方法

- 全WAVを48 kHz・同一長・同一チャンネル数で比較した。
- Hann窓16,384 samples、hop 8,192 samplesのSTFTを使った。
- 各帯域のFFTパワーを全フレーム・全チャンネルで平均し、前工程との差をdBで算出した。
- 「21–24 kHz相対差」は、21–24 kHzの変化から全体RMSの変化を引いた値。全体音量とは別に、その帯域が相対的にどれだけ増減したかを示す。
- 分離直後純粋加算は、保存済みのraw 4Stemを無係数加算して48kHzへ変換した。Stem分離、補正、再ミックス、マスタリングは再実行していない。

## 確認できた結論

1. 元の指摘どおり、Stem再ミックス→最終版では20 Hz–2 kHzが`-1.888 dB`、150–500 Hzが`-1.808 dB`下がり、高域の減少は小さかった。その結果、高域が相対的に前へ移った。
2. ただし全体RMSも`-1.827 dB`下がっている。全体RMS差を除いた150–500 Hzは`+0.019 dB`で、低中域の相対量は減っていない。したがって、150–500 Hzを一律`+0.5〜1.0 dB`増やす必要性は測定結果からは確認できない。
3. 高域の相対移動は確認された。Stem再ミックス→最終版で8–20 kHzは全体RMSに対して`+1.605〜+1.824 dB`前へ移った。
4. 元の指摘どおり、21–24 kHzは原音よりStem再ミックスで`+11.617 dB`、最終版で`+11.996 dB`増えた。
5. 分離直後純粋加算は原音比`-0.863 dB`であり、Stem分離後の無係数再構成は増加原因ではない。
6. 最大の増加区間は分離直後純粋加算→補正済み純粋加算の`+10.835 dB`である。Stem別では補正後ボーカルがraw比`+18.557 dB`で最大だった。ドラムは`+4.088 dB`だった。
7. 補正済み純粋加算→Stem再ミックスでも`+1.645 dB`増えた。
8. マスタリング内では、音色`+0.767 dB`、ダイナミクス`+0.749 dB`、Air`+0.562 dB`で増え、ディエッサーとラウドネスで減少した。最終的なマスタリング差は`+0.379 dB`だった。
9. 倍音工程の選択的な増加は相対`+0.013 dB`で小さく、最終高域保持は音声を変更していない。
10. Air工程には別のfocused testで折り返しが確認されているが、今回の曲の21–24 kHz増加の中心はマスタリング前のStem補正、特にボーカル補正である。Airだけを直しても今回の増加の中心は残る。
11. 補正内部の工程別WAVとログは保存されていないため、rawボーカル→補正後ボーカルのどの内部処理で増えたかは、既存データだけではこれ以上分割できない。
12. Stem再ミックス→最終版の8–20 kHz相対移動は、音色工程で`+0.931〜+0.943 dB`、ダイナミクス工程で`+1.461〜+1.762 dB`、Air工程で`+0.132〜+0.163 dB`増えた。ディエッサーは`-0.400〜-0.448 dB`、ラウドネス工程は`-0.420 dB`戻した。
13. 高域寄りのバランスの中心は、Airではなく音色とダイナミクスの高域移動が重なったことにある。150–500 Hzを追加する方法ではなく、この累積を抑えることが一つ目の指摘に対応する修正対象である。
14. 元の二つの指摘には別々の修正対象がある。一つ目はマスタリングの音色・ダイナミクスによる累積高域移動、二つ目はマスタリング前のStem補正、特にボーカル補正による21–24 kHz生成である。片方だけの修正では両方を解消できない。
