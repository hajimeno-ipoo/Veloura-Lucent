# 通常モード・Stemモード 共通問題比較

## 結論

- 相対的な高域前進は、通常モードとStemモードの両方で発生した。
- 21–24 kHzの増加も、通常モードとStemモードの両方で発生した。
- したがって、どちらか一方だけではなく、両モードが共有する補正処理とマスタリング処理を修正対象にする必要がある。
- 150–500 Hzの相対量は両モードとも減っていないため、150–500 Hzを一律に増やすことは今回の実測から支持されない。

## 比較条件

- 共通入力: Stemセッション `e5a3d718-f8cf-401f-9776-e5644dd0b2b9` の `canonical-input-44100.wav` を48 kHzへ読み込んだ全246.2秒
- 通常モード: 補正 `.balanced`、解析 `.cpu`、マスタリング `.streaming`
- Stemモード: 保存済みの同一セッションのStem再ミックス、工程別マスタリングWAV、分離前後・補正前後WAV
- 測定: Hann窓16,384 samples、hop 8,192 samples、全フレーム・全チャンネルの帯域FFTパワー平均
- 相対差: 各帯域の変化から全体RMS変化を引いた値

## 一つ目: マスタリング後の相対的な高域前進

| モード | 全体RMS | 20 Hz–2 kHz | 20 Hz–2 kHz相対 | 150–500 Hz相対 | 8–12 kHz相対 | 12–16 kHz相対 | 16–20 kHz相対 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 通常 | -0.395 dB | -0.455 dB | -0.060 dB | +0.164 dB | +1.774 dB | +1.718 dB | +1.641 dB |
| Stem | -1.827 dB | -1.888 dB | -0.061 dB | +0.019 dB | +1.824 dB | +1.708 dB | +1.605 dB |

両モードは全体音量の変化量こそ異なるが、全体RMSを除いた20 Hz–2 kHzと8–20 kHzの相対変化はほぼ同じだった。通常モードでもStemモードでも、低域だけが選択的に減ったのではなく、マスタリングで高域が相対的に前へ移っている。

通常モードの主な工程別相対差:

| 工程 | 8–12 kHz | 12–16 kHz | 16–20 kHz |
|---|---:|---:|---:|
| 音色 | +0.901 dB | +0.898 dB | +0.910 dB |
| ディエッサー | -0.414 dB | -0.340 dB | -0.325 dB |
| ダイナミクス | +1.618 dB | +1.449 dB | +1.324 dB |
| Air | +0.175 dB | +0.192 dB | +0.170 dB |
| ラウドネス | -0.425 dB | -0.425 dB | -0.425 dB |

通常モードでも、Stemモードで確認済みだった音色とダイナミクスの累積が中心だった。

## 二つ目: 21–24 kHzの増加

| 区間 | 21–24 kHz変化 | 全体RMSを除いた相対差 |
|---|---:|---:|
| 通常 入力→補正最終 | +25.535 dB | +26.676 dB |
| 通常 サ行・シマー保護後→高域補完後 | +26.961 dB | +27.292 dB |
| 通常 補正後→マスタリング最終 | +1.797 dB | +2.192 dB |
| 通常 入力→最終版 | +27.332 dB | +28.868 dB |
| Stem 分離直後純粋加算→補正済み純粋加算 | +10.835 dB | — |
| Stem 補正済み純粋加算→再ミックス | +1.645 dB | — |
| Stem 再ミックス→最終版 | +0.379 dB | +2.206 dB |

通常モードでは、補正内部の `サ行・シマー保護後→高域補完後` だけで21–24 kHzが +26.961 dB増えた。現行コードではこの境界が `CorrectionHarmonicRepair` の実行に一致する。

`CorrectionHarmonicRepair` は入力スペクトルのbinを2倍位置へ移し、16 kHzからNyquistまでへ加算する。さらに同工程内で `tanhf` による非線形処理を行う。通常モードは `AudioProcessingService → NativeAudioProcessor`、Stemモードは `StemCorrectionService → NativeAudioProcessor` を通じて、この同じ処理を使用する。

マスタリングでも両モードとも21–24 kHzが全体RMS比で約 +2.2 dB前へ移った。通常モード内では音色 +0.754 dB、ダイナミクス +0.806 dB、Air +0.624 dBの絶対増加を確認した。

## 修正要否の判定

| 対象 | 通常モード | Stemモード | 判定 |
|---|---|---|---|
| 音色・ダイナミクス累積による相対的な高域前進 | 発生 | 発生 | 共有マスタリング処理の修正が必要 |
| 高域補完による21–24 kHz生成 | 発生 | 発生 | 共有補正処理の修正が必要 |
| マスタリング内の21–24 kHz追加増加 | 発生 | 発生 | 共有マスタリング処理でも抑制が必要 |
| 150–500 Hz一律増加 | 相対減少なし | 相対減少なし | 採用根拠なし |

## 制限

- 通常モードの解析モードは `.cpu` で実行した。補正DSPとマスタリングDSPは本番と同じ現行実装である。
- 数値は帯域エネルギーの変化を示す。聴感上の良し悪しそのものは、この数値だけでは断定しない。
- コード変更は行っていない。
